beb personal test backups

This is a private backup tool for the owner's beb test environment. It is not a public backup service.

An owner-controlled GitHub Actions runner creates encrypted backups of beb test business records, contracts, photos and settings in the owner's Google Drive, then verifies a downloaded copy through a disposable restore. Morning invoice and receipt PDF files are excluded; payment and document metadata remain.

The Google connection requests account identity and access only to Drive files the backup app creates or that the owner explicitly makes available to it. It does not request access to Gmail, Calendar or the owner's entire Drive.

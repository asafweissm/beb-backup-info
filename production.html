beb production backups

A private backup tool for the owner's beb production environment. It is not a public backup service.

An owner-controlled Google Cloud Run job creates encrypted backups of business records, settings, contracts and photos in the owner's private Google Drive. It downloads and decrypts each upload and checks it through a disposable local database restore. Morning PDF files are excluded; payment and document metadata remain.

The Google connection requests account identity and access only to Drive files the backup app creates or the owner explicitly makes available to it. It does not request Gmail, Calendar or entire-Drive access. The production app, credentials and folder are separate from the test backup setup.
